# 시역 음성 녹음·생성 안내

장면 대사를 인물 목소리로 녹음하거나 AI 음성 서비스로 만들 때 쓰는 대본과 안내다.

## 앱에 넣기

만든 파일을 `app/src/main/res/raw/`에 `voice_<번호>.mp3` 이름 그대로 넣고 다시 빌드하면, 그 대사가 나올 때 녹음이 재생된다(배경음악은 그동안 줄어든다). 파일이 없는 줄은 기기 음성(TTS)으로 읽는다. 번호와 대사의 짝은 `game/VoiceCatalog.kt`가 정하고, 대본과 같은 번호를 쓴다.

| 구간 | 적용 |
| --- | --- |
| 프롤로그 `prologue_01~17` | 적용(2026-11-15) |
| 장소별 이동 중·도착·단서 해금, 엔딩 | 아직 |

대사를 고친 뒤에는 대본을 다시 뽑아 번호가 밀리지 않았는지 확인한다. 이미 만든 녹음과 대사가 어긋나면 그 줄은 다시 녹음해야 한다.

## 파일

| 파일 | 내용 |
| --- | --- |
| [script.md](script.md) | 장면별 대본(읽기용) |
| [script.csv](script.csv) | 같은 내용의 표(엑셀·구글 시트에서 열기, 음성 서비스 일괄 입력용). 열: 번호, 파일 이름, 구간, 화자, 대사, 배경 |

대본은 코드에서 뽑는다. 대사를 고친 뒤 다시 뽑으려면:

```bash
EXPORT_VOICE_SCRIPT=docs/voice ./gradlew testDebugUnitTest --tests "*VoiceScriptTest" --rerun-tasks
```

**번호는 장면 안 순서로 붙는다.** 줄을 중간에 넣거나 빼면 뒤 번호가 밀리므로, 녹음을 시작한 뒤에는 대사 수정 시 번호를 함께 확인한다.

## 녹음·생성 규칙

- **파일 이름:** `voice_<번호>.mp3` (예: `voice_prologue_03.mp3`). 영문 소문자·숫자·밑줄만.
- **형식:** MP3 또는 OGG, 모노, 44.1kHz 이상, 줄마다 앞뒤 무음 0.2초 이내.
- **음량:** 줄마다 비슷하게(약 −16 LUFS). 외치는 대사도 터지지 않게.
- **괄호 지시문:** `(멀리서)`처럼 괄호 안 글은 읽지 않고 연기로만 표현한다.
- **‘…’과 말줄임:** 실제 쉼으로 표현한다.
- **이동 중 구간(“주행 중 음성”):** 운전 중에 소리로만 듣는 부분이라 화면 없이도 누가 말하는지 알 수 있게 목소리 차이를 분명히 한다. 놀래는 효과음·비명은 넣지 않는다.
- **엔딩 마지막 줄**(`— 진 엔딩 · 연이의 이름 —` 등)은 제목 카드라 녹음하지 않아도 된다.

## AI 음성 서비스를 쓸 때

- 인물마다 목소리 하나를 정해 모든 줄에 같은 목소리를 쓴다(내레이션 포함 8개).
- 상업 이용·재배포가 허용되는 요금제인지, 생성한 음성의 저작권·사용 범위를 확인하고 사용한 서비스와 조건을 이 문서 아래에 남긴다.
- 실존 인물(배우·성우)의 목소리를 흉내 낸 음성은 쓰지 않는다.

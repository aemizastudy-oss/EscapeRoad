# 로비 위치 편집

기준일: 2026-11-13. 로비에서 제목·로고·버튼 등의 위치를 직접 확인하며 조정하는 debug 전용 도구입니다. 편집하지 않은 기본 로비의 배치를 유지하고, 저장한 위치 차이를 실제 화면 요소에 적용합니다. 게임·관광 진행이나 SDK 설정을 수정하는 기능은 아닙니다.

## 사용 순서

1. debug 앱의 로비에서 안전한 P·실제 정지·CarUx 게임 허용·foreground 상태를 확인합니다. MOCK 시연에서는 개발 패널의 PARKED를 사용하며 실제 차량 관측과 구분합니다.
2. 오른쪽 위 **로비 배치 편집**을 엽니다. 현재 선택한 요소가 표시되며 편집 중에는 요소 위의 선택·드래그 영역이 원래 버튼의 터치를 가로챕니다.
3. 요소를 직접 끌거나 선택 목록에서 골라 상하좌우 이동 버튼으로 조정합니다. 이동 단위는 1dp와 10dp 사이에서 바꿀 수 있습니다.
4. **저장**을 누르면 현재 화면 프로필의 위치를 기기에 저장하고 편집기를 닫습니다. 저장 실패 시 편집 상태를 유지하므로 안내를 확인하고 다시 시도할 수 있습니다.
5. **취소**는 저장하지 않은 변경을 버리고 마지막 저장 배치로 돌아갑니다. **기본값**은 현재 프로필의 초안을 기본 배치로 바꾸며, 저장을 눌러야 영구 적용됩니다. 기본값을 누른 뒤 취소하면 이전 저장 배치를 유지합니다.

조작 패널이 요소를 가리면 **접기**를 눌러 드래그하고 **펼치기**로 돌아옵니다. 표시하는 x·y는 자동 배치 기준의 이동량이며, x 양수는 오른쪽, y 양수는 아래입니다. 배경 이미지와 요소 크기·글자 내용은 이 도구에서 편집하지 않습니다.

주행·주차 미확인·UX 제한·foreground 상실 등 안전 조건이 풀리면 편집기를 닫고 저장하지 않은 변경을 버립니다. 다시 안전한 상태가 되어도 버린 초안을 자동 저장하거나 복구하지 않습니다. 화면 프로필이 바뀌는 경우에도 저장하지 않은 변경을 현재 프로필에 몰래 적용하지 않습니다.

## 이동하는 요소

| ID | 요소 |
| --- | --- |
| `WELCOME` | Welcome, Detective 문구 |
| `LOGO` | ESCAPE ROAD 로고 |
| `TAGLINE` | 영문 보조 문구 |
| `TITLE` | 한국어 제목 |
| `DESCRIPTION` | 시작 안내 문구 |
| `ACTIONS` | 수원 코스·SDK 상태·사건 선택·기록부·저장된 수사 버튼 묶음 |
| `RESUME` | 저장 세션이 있을 때 나타나는 수사 재개 카드 |

`ACTIONS`는 버튼 행 전체를 하나로 이동합니다. 개별 버튼의 문구·순서·동작을 편집하지 않습니다. 저장 후에는 그림과 함께 실제 터치 영역도 이동하며, 편집기를 닫은 뒤 버튼의 원래 기능을 사용할 수 있습니다. 세션이 없는 경우 `RESUME` 카드가 새로 만들어지는 것은 아닙니다.

이동은 로비 배치 영역의 경계 안으로 제한하지만 요소끼리 겹치지 않도록 자동 정렬하지는 않습니다. 로고·문구·버튼의 가독성과 터치 영역을 실제 화면에서 함께 확인합니다.

## 저장과 팀 공유

넓은 화면 `WIDE`와 좁은 화면 `COMPACT`의 위치를 별도로 관리합니다. 한 프로필의 저장이 다른 프로필의 위치를 덮어쓰지 않으며, Activity 재생성이나 앱 재실행 후 저장된 배치를 다시 읽습니다. 이 위치는 해당 기기의 로컬 설정이며 다른 팀원 기기로 자동 동기화되지 않습니다.

- 기본 설정: `app/src/main/assets/lobby_layout.json`
- 기기 저장소: SharedPreferences `roadescape-lobby-layout`의 `settings_json`
- 형식: `schemaVersion: 1`, `wide`·`compact` 아래 요소별 `xDp`·`yDp`
- 저장 경계: 게임의 `game-session.json`, 관광의 `tour-state.json`, 수첩·평가 설정과 별개

설정 읽기나 형식 검증에 문제가 있으면 기본 배치를 사용하고 편집 패널에서 경고합니다. 읽기 실패만으로 원본 설정을 자동 삭제하거나 덮어쓰지 않습니다. **JSON 복사**는 현재 프로필의 초안과 다른 프로필의 저장값을 묶어 복사하며 기기 저장은 별도입니다. 위치 변경을 공유하려면 복사한 내용으로 기본 asset 파일을 검토·수정하고 debug/release를 다시 빌드해 적용 화면을 확인합니다. APK 안의 asset은 앱에서 저장 버튼을 누르는 것만으로 수정되지 않습니다. 팀원이 기존 로컬 배치를 저장했다면 그 설정이 남아 있으므로, 새 기본값을 적용하려면 해당 프로필에서 기본값을 확인하고 저장합니다.

## 검증 범위

기기 회귀 코드는 `LobbyLayoutEditorTest`에 작성합니다. 로고 드래그·저장·재생성, 편집 중 버튼 터치 가로채기와 저장 후 실제 버튼 터치 영역, 취소·기본값·주행·foreground 상실의 무저장을 확인하고 게임 스냅샷의 불변성을 검사합니다. 테스트는 편집기 설정만 별도로 보관·복원하며 기존 게임을 초기화하지 않습니다.

이 문서는 사용법과 저장 경계를 설명합니다. 현재 변경의 빌드·기기 실행·화면 확인 완료를 뜻하지 않으며, 실제 결과와 남은 항목은 [검증 기록](verification.md)에 구분해 남깁니다. MOCK 편집 시험을 LIVE 차량·SDK 안전 신호의 새 검증 결과로 표시하지 않습니다.

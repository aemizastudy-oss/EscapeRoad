# 시연 영상 풀이 순서

코드(flow5, `SiyeokFlow5.kt`) 기준 정답과 누르는 순서다. debug 빌드 · 시연 MOCK 모드 기준.

## 0. 시작 준비

1. 로비 오른쪽 위 **시연 · SIM ▾** → **시연 MOCK** 선택 → **P 정차**
2. **사건 고르기** → **이 사건을 맡겠습니다** → **시간 이동 시작**
3. 프롤로그: **다음**으로 넘기기(보이스 재생) 또는 **건너뛰기**

## 장소마다 반복하는 흐름

**출발하기** → 패널 **D 주행**(이동 중 음성) → **P 정차** → **도착한 것으로 하기 (시연)** → **관광 시작** → **15분 경과 시연** → **차로 돌아왔어요** → 탐색 장면 **수색 시작**
→ 다 풀면 **다음 단서** → **○○ 경로 보기** → 다음 장소 **출발하기**

탐색 장면: 장소를 누르고 **자세히 보기** → 자물쇠 풀기. 문서는 **사건 기록부**에서 읽는다.

## 다른 엔딩 보여 주기

- **일반 엔딩:** 마지막 진상 추리 둘 중 하나를 틀린다. 그 뒤 **진상 다시 추리하기**로 재도전 장면도 찍을 수 있다.
- **배드 엔딩:** **주변 살피기 · 각성도 +1**과 힌트를 많이 써서 각성도 8 이상으로 끝낸다.

## 바로가기 (처음부터 안 풀어도 됨)

**P 정차** 상태에서 **시연 · SIM ▾** 패널의 시연 바로가기:

- **도착 1~5:** 그 장소에 막 도착한 상태
- **장면 1~5:** 그 장소 탐색 장면, 손대기 전 상태
- **엔딩 공개 / 진 / 일반 / 배드:** 마지막 공개 화면이나 각 엔딩으로 바로

## 30~60초 영상 추천 컷

1. 프롤로그 2~3줄 (보이스) — 5초
2. 출발하기 → D 주행, 이동 중 음성 — 5초
3. 도착 → 관광 시작 → 차로 돌아왔어요 — 5초
4. 탐색 장면 하나 (화성행궁: 현판 壽 → 봉투 水) — 10초
5. 차량 조작 퍼즐 (판문 깜빡이 또는 독서등 봉화) — 10초
6. 진상 추리 → 진 엔딩 드라마 → 보고서 — 10초
7. 여행 도우미 화면 — 5초

화면 구석에 **MOCK · 개발용 시연 데이터** 표시가 보이도록 찍는다(실차 연동이 아닌 시연임을 밝힘).

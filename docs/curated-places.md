# 직접 준비한 장소 자료

확인일: 2026-11-15. 네이버 검색 응답을 재사용하지 않고 공식 안내에서 장소명·분류·주소만 확인해 8개 카드를 수동 구성했다. 웹 문단·사진·리뷰·지도 타일을 복제하지 않았다. 아래 링크는 자료 출처이며 앱 실행 중 외부 API를 요청하지 않는다. 공공기관이 안내한다는 이유만으로 모든 저작물에 무제한 사용권이 있다고 주장하지 않는다.

개별 장소의 현재 영업·빈자리·입구 좌표는 검증하지 않았다. 따라서 장소 좌표는 null로 유지하고 길 안내는 `주변 관광지로 안내`로 표시한다. 기존 GuideStops의 관광지 대표점까지 안내를 요청하며 입구 안내나 도착 성공을 보장하지 않는다. 자료를 추가할 때는 사실 확인일·출처·안내 대상 좌표의 근거를 함께 갱신한다.
